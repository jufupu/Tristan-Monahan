# My Must-Have VSCode Extensions

## 🛠 Core Tools
- Prettier – Code formatter
- ESLint – Linting
- GitLens – Git superpowers

## 💡 Productivity & UI
- TODO Highlight – Highlight `TODO:` and `FIXME:`
- Bracket Pair Colorizer – Easily track code blocks
- Live Server – Local dev server with hot reload

## 🎨 Frontend Dev
- React Snippets
- Tailwind CSS IntelliSense
- Color Highlight – Show actual colors in CSS
